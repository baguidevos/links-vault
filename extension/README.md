# 🚀 Links Vault Clipper - Extension Chrome (Manifest V3)

L'extension officielle **Links Vault Clipper** vous permet de capturer, enrichir et sauvegarder n'importe quelle page web, vidéo YouTube, article ou document directement dans votre coffre-fort **Links Vault** en un seul clic.

---

## 📦 Installation dans Google Chrome (ou Brave / Edge)

1. Ouvrez votre navigateur Chrome et rendez-vous sur `chrome://extensions/`.
2. Activez le **Mode développeur** (interrupteur en haut à droite).
3. Cliquez sur le bouton **« Charger l'extension non empaquetée »** (Load unpacked).
4. Sélectionnez le dossier `extension` situé à la racine du projet :
   ```
   c:\Users\D3vOs\Projets\Laravel\Web\links-vault\extension
   ```
5. L'icône **Links Vault Clipper** apparaît désormais dans votre barre d'extensions ! Épinglez-la pour un accès rapide.

---

## ⚡ Utilisation

### 1. Première connexion
- Cliquez sur l'icône de l'extension.
- Renseignez l'URL de votre serveur (ex: `http://localhost:8000`).
- Connectez-vous avec votre **email et mot de passe**, ou collez votre **Personal Access Token**.

### 2. Enregistrer un lien
- Rendez-vous sur n'importe quel site ou vidéo YouTube.
- Cliquez sur l'extension (ou raccourci **`Alt + S`**).
- L'extension extrait instantanément le titre, l'image d'aperçu, la favicon et la description.
- Choisissez votre **Espace / Team**, **Dossier**, **Catégorie** et ajoutez vos **Tags**.
- Activez ou désactivez le **Résumé IA 🤖** ou le marqueur **Favori ⭐**.
- Cliquez sur **« Enregistrer dans le Vault »**.

### 3. Clic droit (Menu Contextuel)
- Faites un clic droit sur n'importe quelle page : **« Enregistrer cette page dans Links Vault »**.
- Faites un clic droit sur un lien hypertexte : **« Enregistrer ce lien dans Links Vault »**.
- Sélectionnez du texte et faites un clic droit : **« Enregistrer la sélection dans Links Vault »**.
